# FASE 1 — ARQUITECTURA BASE

## Sistema de Inventario y Ventas para Librerías

Quiero construir un sistema profesional de inventario y ventas para librerías.

El sistema estará compuesto inicialmente por:

1. Aplicación móvil Android/iOS.
2. Aplicación Desktop para Windows.
3. Firebase Authentication.
4. Firebase SQL Connect.
5. Cloud SQL for PostgreSQL.
6. SDKs tipados generados por Firebase SQL Connect.

La base de datos principal será PostgreSQL administrada mediante Cloud SQL y conectada a la aplicación mediante Firebase SQL Connect.
