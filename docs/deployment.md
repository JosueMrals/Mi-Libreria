# Deployment

## Reglas

- No se ejecuta despliegue a producción sin autorización explícita.
- El proyecto se prepara para el despliegue oficial de Firebase SQL Connect.
- Solo se usará la herramienta oficial de Firebase.

## Comando previsto

```bash
firebase deploy --only dataconnect
```

## Recomendación

Este comando debe ejecutarlo el propietario del proyecto y no el agente, salvo instrucción explícita.
